Knock Knock: Brewed Up Joe's Return to Raw Hip-Hop Basics

There is a particular pleasure in hearing hip-hop strip itself back down to essentials, and that is exactly the mission behind "Knock Knock," the new release from J/O/E, also known as Brewed Up Joe. Released on 28th August 2026, the track is a deliberate revert back to raw hip-hop basics: a heavy, mysteric loop beat paired with unapologetic rhymes that carry both substance and a slight, knowing sense of humor.
